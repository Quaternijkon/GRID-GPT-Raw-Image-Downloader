# GRID GPT Raw Image Downloader

一个纯客户端的 Chrome Manifest V3 扩展，用于导出 ChatGPT 图库和资料库中的原图、元数据，并可选择按恢复出的用户提示词分组。项目为非官方工具。

## 更新日志

### 1.9.19 · 2026-09-27

- 重新设计导出设置：统一中文文案，将“新建导出、恢复失败任务、性能设置”拆成独立区域；自动发现的原图/提示词恢复入口置顶，手动结果报告导入收进可展开区域。
- 下载进度面板改为中文阶段说明，明确区分“提示词未解析、提示词文件失败、原图失败、正在恢复、已排队和警告”，避免把 10 个提示词错误误读成 35 个原图失败。
- 暂时性网络错误会出现独立恢复提示，说明任务正在等待且尚未计为终态失败；自适应降速原因也会转换为可读中文。
- 改进窄屏和小窗口布局：设置字段自动改为单列，进度面板扩大信息密度并保持可滚动、可收起。

### 1.9.18 · 2026-09-27

- 提示词分组目录改为由完整规范化提示词生成的稳定内容地址 `p-<hash>-<length>`；同一提示词无论首次导出还是稍后恢复，都得到完全相同的目录，不会因其他提示词当时失败而改变编号。
- 提示词重试成功后不再只写 `未解析/000001-prompt.txt`：插件会重新取得该张原图，写入其最终提示词目录，生成相同的 `prompt.txt`，等待新文件完成后删除旧的“未解析”原图。只有目录、文件名和旧文件清理全部完成才记为恢复成功。
- 暂时无法解析的图片改放到与输出目录并列的 `<目录>-recovery/未解析`，不再污染最终输出目录；恢复后即使浏览器留下空的恢复文件夹，正式目录仍与一次成功时完全一致。
- 原图终态失败会自动保存独立检查点。下次设置窗口提供“一键重试上次失败的 N 张原图”，只下载失败图片；成功图片、提示词会话和图库分页均不重复请求。重试使用覆盖目标路径，避免不确定提交产生 `(1)` 文件。
- 旧版下载结果 JSON 也可手动导入：若报告含原图失败项，插件优先只重试这些原图，并保留旧版数字分组目录，使恢复结果与该次旧版成功下载的布局一致。
- 提示词与原图检查点按页面和下载目录分别保存；原图重试成功后若其提示词仍未解析，会把新的 Chrome 下载 ID 自动交给提示词检查点，保证后续恢复可安全移动并清理旧文件。

### 1.9.17 · 2026-09-26

- 修复原图内部 3 轮重试耗尽后丢失“暂时错误”属性、导致下载队列把网络错误过早计为终态 `failed` 的问题。
- 原图遇到超时、网络失败、HTTP 408/429/5xx 等暂时错误时，在已有 3 轮候选端点重试之外，再进入最多 12 轮串行恢复；等待时间为 10、20、40 秒，随后每轮最多 60 秒。恢复队列一次只复核一张，避免网络恢复时并发放大请求。
- 暂时错误在恢复阶段显示为 `retrying/backoff`，不会计入 `failed`；只有非暂时错误，或完整恢复预算耗尽后，才成为终态失败。报告记录累计请求次数、错误和恢复轮数。
- 当前已经开始的 1.9.16 下载保持原代码运行，不会被自动中断；1.9.17 在下次刷新并重新加载扩展后生效。

### 1.9.16 · 2026-09-26

- 提示词导出完成后，插件按当前 ChatGPT 页面自动保存最小化的未解析清单；下次打开下载设置时直接显示“一键重试上次未解析”，用户不再需要寻找或导入结果 JSON。手动导入仍作为备用方式保留。
- 对可能由会话数据暂时未同步造成的 `target_not_found`、响应格式或 JSON 异常，在同一次导出结束前自动按 10 秒节奏复核一次；只复核失败项，不重新扫描图库或下载原图。
- 解析器可自动跳过未来新增的、完全不含图片指针的 assistant/tool 显示信封；未知且携带图片资源的结构仍明确报错，避免错误关联提示词。
- 检查点只保存图片 ID、会话 ID、编号、路径和错误诊断，不保存完整会话正文或登录令牌；按页面隔离并最多保留 10 份。
- 生成的 `prompt.txt` 和编号提示词侧文件若被 Chrome 明确拒绝，会原路径自动重试最多 3 次；仍失败会明确写入报告，编号侧文件还会保留在一键恢复检查点中。

## 当前边界

- ChatGPT 的内部接口及限流策略可能变化；原图可下载，不代表会话消息中仍有对应的生成输出。
- 缺失生成输出或附件内容时，不根据标题、相邻图片或缩略图编造提示词。
- 浏览器接受下载请求并不等于文件已完成磁盘写入。
