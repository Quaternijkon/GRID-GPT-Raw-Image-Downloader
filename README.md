# GRID GPT Raw Image Downloader

一个纯客户端的 Chrome Manifest V3 扩展，用于导出 ChatGPT 图库和资料库中的原图、元数据，并可选择按恢复出的用户提示词分组。项目为非官方工具。

## 更新日志

### 1.9.11 · 2026-09-26

- 可导入上次生成的下载结果 JSON，仅对 `promptStatus: unresolved` 的图片按会话去重重试提示词；不重新分页图库或下载原图。
- 恢复成功时，在旧目录的“未解析”中按图片编号写入独立的 `000068-prompt.txt` 等文件；另存定向重试结果 JSON，保留仍失败的图片 ID、会话 ID、错误和结构诊断。下次可导入该重试报告，只处理剩余失败项。
- 针对 1.9.10 结果确认：100 张未解析原图都在磁盘上，涉及 43 个会话；旧错误为 90 个 `unsupported_content`、8 个 `target_not_found`、2 个 `missing_base`。旧报告缺少足以安全修复 90 个解析错误的具体内容类型，新诊断会记录类型与字段；不会从标题或邻近图片猜测提示词。
- 只做静态检查和旧报告筛选核对；尚未在登录会话中完成这 43 个会话的真实定向重试。

### 1.9.10 · 2026-09-25

- 保存提示词时串行读取会话，每条请求完成后固定间隔 **10 秒**；遇到 429 再额外等待 **10 秒**，若服务端要求更久则遵守其时间。
- 移除插件自行指数拉长到几分钟的请求间隔。413 个会话仅固定间隔约需 **69 分钟**，还不含响应和服务端等待时间。
- 原图下载的并发策略保持不变。此节奏不能保证 ChatGPT 不返回 429；本版本尚未执行自动测试或完整真实导出。

### 1.9.9 · 2026-09-24

- 将触发 429 后的每条会话间隔上限从 5 分钟降为 **10 秒**，初始串行 1 秒间隔不变。
- 将服务端 `Retry-After` 与插件自行退避分开显示；无服务端时间时使用最长 5 分钟的整批冷却，随后继续重试同一会话。
- 当前图库列表和图片详情没有发现可替代完整会话读取的准确提示词数据源；服务端配额未公开，不能保证完全不触发 429。
- 已更新静态检查与回归用例定义；尚未执行自动测试或完整真实导出。

### 1.9.8 · 2026-09-24

- 独立整理当前 GRID 代码，移除早期项目的脚手架和过期材料。
- 支持原图字节保留、分页发现、按创建时间的全局编号、增量边界及详细结果报告。
- 支持从实际会话父链恢复提示词，按累计文字分组；无法可靠恢复的图片单独标记。
- 提示词会话串行读取，初始请求间隔为 **1 秒**；遇到 HTTP 429 后遵守服务端等待时间并降低频率。图片下载使用独立的自适应或手动并发。
- 当前版本已做静态检查并保留回归用例定义；尚未完成自动测试和全量真实环境验证。

详细模块职责见 [架构说明](docs/ARCHITECTURE.md)，版本记录见 [CHANGELOG.md](CHANGELOG.md)。

## 当前边界

- ChatGPT 的内部接口及限流策略可能变化；原图可下载，不代表会话消息中仍有对应的生成输出。
- 缺失生成输出或附件内容时，不根据标题、相邻图片或缩略图编造提示词。
- 浏览器接受下载请求并不等于文件已完成磁盘写入。
