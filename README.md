# GRID Media Exporter

一个纯客户端的 Chrome Manifest V3 扩展。可从 ChatGPT 图库与资料库、Gemini Library 导出原图和可选提示词，也可从 Grok Imagine 导出图片、视频及提示词。项目为非官方工具。

版本按支持平台的迭代划分：ChatGPT 为 1.x，Grok 为 2.x，Gemini 为 3.x。当前版本为 **3.0.5**。

## 当前边界
